FOUND ISSUES
------------
1. Kernel regression risk: linux-zen 7.2.2 has CONFIG_ANDROID_BINDER_IPC_RUST=y, classic CONFIG_ANDROID_BINDER_IPC is not set. Known Waydroid regression on 6.18+ kernels; see github.com/waydroid/waydroid/issues/2157. Session does boot here, but audio/transaction issues have been reported on same kernel config pattern.
2. Image mismatch: waydroid-image-gapps is installed, but init used VANILLA system_type. This may explain missing vendor.audio-hal-2-0.
3. Missing HAL: vendor.audio-hal-2-0 binary not found. dmesg: "Could not start service 'vendor.audio-hal-2-0' as part of class 'hal': Cannot find '/vendor/bin/hw/android.hardware.audio@2.0-service'".
4. cgroup read-only errors: Android init tries to create cgroups under /sys/fs/cgroup but gets "Read-only file system". Non-fatal, but indicates cgroupv2 layout mismatch.
5. lxc.hook.post-stop failure: lxc-start script exits 126 during shutdown. Repeated in waydroid.log. Non-fatal, but noisy.
6. IP address UNKNOWN: container IP not reported to host. DHCP traffic visible in dmesg, but waydroid status cannot fetch container IP.
7. No ashmem_linux module: modprobe ashmem_linux fails. Binderfs exists via /dev/binderfs, but ashmem is absent.
8. waydroid session start initially failed with DBUS_SESSION_BUS_ADDRESS autolaunch disabled; fixed by exporting DBUS_SESSION_BUS_ADDRESS and XDG_RUNTIME_DIR explicitly.
