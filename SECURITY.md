# Security Policy

## Scope

This repository contains system logs and security audit findings from a personal Linux desktop. It is provided for transparency and public review.

## What's included

- Attack detection logs (suspicious process monitoring)
- Audit rule configurations (not active/runtime data)
- System diagnostic reports (Waydroid, kernel, network)
- Project self-heal/debug logs
- Security findings analysis

## What's NOT included

- No credentials, API keys, wallet addresses, or secrets
- No packet captures or network traffic data
- No authentication logs (auth.log not present on system)
- No auditd runtime data (auditd not active)

## Mining activity

The logs show crypto mining processes (SRBMiner, minerd) running under the system user's account. These are self-operated mining rigs using the user's own hardware. Wallet addresses in the process command lines are the user's own mining wallets. This is not evidence of compromise — it is evidence of intentional mining activity.
